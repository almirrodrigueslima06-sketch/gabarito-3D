# gabarito-3D
projeto gabarito em 3d para marcaçoes de pontos eletricos. Criado com claude 
Impressão:

Imprima a haste em pé, com o furo para baixo. A altura é de 209,5 mm, então a sua impressora precisa de pelo menos 210 mm de altura (eixo Z).
Use PETG com 4 perímetros. Se a haste ficar muito flexível, aumente o preenchimento ou use um cabo de vassoura de 12 mm no lugar.
O encaixe tem folga de 0,2 mm e é justo, mas pode soltar ao puxar o gabarito da parede. Para travar, há um furo de 3,4 mm em cada encaixe para um parafuso M3, prego ou pino. Ele é opcional.
